# WordFind 关键词雷达

一个 Chrome / Edge 侧边栏扩展，把 Google Trends 关键词调研收进一个中文工作台：批量分析、自动挖词、相关词、翻译、统一词库，以及在 Trends 页面注入快捷按钮。

> 本项目合并了 Chrome 应用商店里 **TrendsBar** 与 **Trends Radar** 两个扩展的功能，并做了独立重写：重复的部分只保留一套，两个扩展的独有功能分别并入工作台和「挖词」页签。代码、界面与数据模型均为重新实现，未复制原扩展代码，与原作者无关联。两个扩展均以打包产物分发，本项目以 MIT 协议开源。

## 合并了什么

### 从 TrendsBar 合并

| 原扩展 | 合并后 |
| --- | --- |
| 「关键词」「对比」「批量查看」各自维护列表与打开逻辑 | 统一为「关键词组」：每行一组，一处输入、一处分析、一处复制链接 |
| 「历史」「收藏」「词根」三个独立存储 | 合并为一条词库记录，用 `favorite` / `root` / `count` 三个字段区分 |
| 趋势图、搜索结果表、搜索框三套页面注入代码 | 合并为一个 `ensureTools` / `ensureBadges` 注入管线 |
| 外部关键词评分服务 `s.trendsbar.net` | 移除，改为展示可验证的相关词与使用次数，不引入无法核实的评分 |

### 从 Trends Radar 合并

| 原扩展 | 合并后 |
| --- | --- |
| Custom / Favorites / History / Roots 等多套关键词列表 | 全部并入统一词库，用收藏、词根、使用次数区分；内置 50 个英文词根可一键导入 |
| Batch Analysis、Root Analysis 两个批量打开页 | 合并为工作台「分析全部」+ 词库「批量分析」，共用最大打开数设置 |
| New Word Mining（自动挖词） | 保留为独立「挖词」页签，是 Radar 的核心独有功能 |
| Google / Twitter / Reddit / Ahrefs / 域名 五个逐词图标 | 合并为词库每行的「查」面板，一次展示五个入口 |
| 对比关键词预设列表 | 合并为挖词页的「对比基准词」预设（含搜索量提示），也可手填 |
| 关键词预处理（连字符、下划线、`.html`、分号） | 并入工作台「整理」按钮 |
| 页面注入的复制 / 收藏 / 搜索 | 复制、对比、分析、收藏、引号、删除合并为一套注入按钮，搜索与难度查询移到「查」面板 |

## 功能

### 关键词工作台

- 每行一组关键词，英文逗号、中文逗号、顿号、分号都能分隔，最多 5 个词一组（Google Trends 对比上限）。
- 去重、排序、整理（去连字符/下划线、去 `.html`、压缩空格）、示例、清空。
- 时间范围：过去 24 小时 / 7 天 / 30 天 / 90 天 / 12 个月 / 5 年 / 自定义日期。
- 地理范围：全球、美国、英国、德国、日本、韩国、中国、中国香港、中国台湾等 19 个常用地区。
- 「分析全部」按设置打开全部组或只打开第一组，并受「最多打开组数」限制。
- 每组卡片支持单独打开、复制链接、加/去引号、翻译、相关词、收藏、删除。
- 点击单个关键词 chip 直接打开该词的趋势页。

### 自动挖词（来自 Trends Radar 的核心能力）

- 种子关键词可手填，也可从工作台输入框、词库、内置 50 个英文词根一键导入。
- 设置地区、时间范围、最大词数、有效阈值、对比基准词。
- 在**独立后台标签页**里运行，不占用也不跳转当前页面；完成后可自动关闭。
- 每批 1 个基准词 + 最多 4 个种子词，读取 Google Trends 的相关搜索与时间线数据，把新发现的相关词继续加入队列。
- 有效新词判定：时间线前两个点为 0、最后三个点不下降、且末点相对基准词达到阈值百分比。
- 支持暂停 / 继续 / 停止；实时显示已处理数、相关词数、有效新词数、下一批倒计时。
- 结果可一键复制、加入输入框、加入词库。
- 每批之间随机等待 4–6 秒，降低触发 Google 限流的概率。

### 词库（历史 + 收藏 + 词根）

- 分析过的关键词自动入库并累计使用次数、记录最近使用时间。
- 收藏与词根是同一记录的标记，不再是多份互不相干的列表。
- 搜索、按标记筛选、按最近使用 / 使用次数 / 名称排序。
- 单条操作：加入输入框、加入第一组对比、复制、外部查询、切换收藏、切换词根、删除。
- 批量操作：加入输入框、批量分析（按 5 个一组切分并受最多打开数限制）、收藏、取消收藏、标记词根、删除。
- 外部查询面板：Google、X / Twitter、Reddit、Ahrefs 关键词难度、域名查询（namebeta）。
- 导出 JSON / CSV，导入 JSON（与现有词库合并）。
- 设置里可一键导入 50 个内置英文词根并标记为词根。

### Trends 页面注入

在 `trends.google.com` 的关键词行、搜索结果表格、搜索框旁注入：

- 复制
- 对比（与第一组关键词一起打开）
- 分析（发送到侧边栏）
- 收藏（直接写入词库收藏）
- 引号（在 URL 的 `q` 参数里切换双引号）
- 删除（仅搜索结果表格/搜索框的紧凑模式，把该词从当前对比中移除）
- 词库标记：★ 收藏、根 词根、数字 已分析次数

相关查询区域额外提供「分析这组相关词」按钮。

### 右键菜单

选中网页文字后右键：

- 「分析选中关键词」：把选中文字送入侧边栏，作为新的一组。
- 「与对比组一起打开」：把选中文字追加到第一组关键词后打开 Trends。

### 设置

- 分析全部时的打开方式、最多打开组数（1–20）。
- Trends 界面语言（中文 / English）。
- 页面注入开关：快捷按钮、词库标记。
- 翻译目标语言（11 种）、翻译后自动复制。
- 挖词默认参数：最大词数、有效阈值、对比基准词、完成后关闭后台标签页。
- 导出 / 导入全部数据、导入内置词根、恢复默认。

## 安装

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录。
4. 点击工具栏图标打开侧边栏；首次使用建议先点「示例」看输入格式。

无需构建、无 npm 依赖，目录即安装包。

## 权限说明

- `storage`：保存设置、输入、词库与挖词进度。
- `sidePanel`：侧边栏。
- `contextMenus`：右键菜单。
- `clipboardWrite`：复制关键词和链接。
- `webRequest`：仅在 `trends.google.com/trends/api/*` 上读取自动挖词所需的 Trends 接口响应。
- `host_permissions`：`trends.google.com`、`suggestqueries.google.com`、`translate.googleapis.com`。

## 数据与隐私

- 所有设置、输入、词库、挖词结果都保存在 `chrome.storage.local`，不经过任何自建服务器。
- 翻译请求发往 `translate.googleapis.com` 的公开端点；相关词请求发往 `suggestqueries.google.com`。
- 自动挖词通过一个后台标签页访问 `trends.google.com`，读取页面自身发出的 Trends 接口响应，不额外上传数据。
- 不加载远程脚本，不注入分析统计，不发埋点。

## 已知限制

- Google Trends 的页面结构与内部接口会变；注入脚本使用常见类名并加了防重复标记，挖词依赖 `/trends/api/widgetdata/*` 的返回格式。如果 Google 改版，需要更新 `content.js` 或 `radar.js` 中的解析逻辑。
- 一组最多对比 5 个关键词，挖词固定为 1 个基准词 + 4 个种子词；超出部分会被截断。
- 自动挖词会连续访问 Google Trends，可能触发限流；已加入每批 4–6 秒随机间隔与失败重试，但仍建议不要长时间高频率运行。
- 首次使用自动挖词前，建议先在普通标签页打开一次 `trends.google.com` 并完成 cookie 同意，否则后台标签页可能拿不到接口数据。
- 挖词的暂停状态依赖后台 Service Worker 存活；如果浏览器回收后台进程，任务会被标记为中断，需要重新开始（结果会保留）。
- 翻译和相关词依赖 Google 免费接口，频繁请求可能被限流。
- 自定义时间格式使用 Google Trends 的 `YYYY-MM-DD YYYY-MM-DD` 约定。
