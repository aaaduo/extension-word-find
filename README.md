# WordFind 关键词雷达

一个 Chrome / Edge 侧边栏扩展，把 Google Trends 关键词调研流程收进一个中文工作台：批量输入关键词组、一键打开趋势对比、抓取相关词、翻译、维护统一的词库，并在 Trends 页面注入快捷按钮。

> 本项目是一个独立重写版本。功能思路参考 Chrome 应用商店里的 TrendsBar 扩展，代码、界面与数据模型均为重新实现，未复制原扩展代码，与原作者无关联。原扩展为闭源打包产物，本项目以 MIT 协议开源。

## 合并了什么

原扩展内部有三套相互重叠的机制，本项目合并为一套：

| 原扩展 | 合并后 |
| --- | --- |
| 「关键词」「对比」「批量查看」各自维护列表与打开逻辑 | 统一为「关键词组」：每行一组，一处输入、一处分析、一处复制链接 |
| 「历史」「收藏」「词根」三个独立存储 | 合并为一条词库记录，用 `favorite` / `root` / `count` 三个字段区分 |
| 趋势图、搜索结果表、搜索框三套页面注入代码 | 合并为一个 `ensureTools` / `ensureBadges` 注入管线 |
| 外部关键词评分服务 `s.trendsbar.net` | 移除，改为展示可验证的相关词与使用次数，不引入无法核实的评分 |

## 功能

### 关键词工作台

- 每行一组关键词，英文逗号、中文逗号、顿号、分号都能分隔，最多 5 个词一组（Google Trends 对比上限）。
- 去重、排序、整理、示例、清空。
- 时间范围：过去 24 小时 / 7 天 / 30 天 / 90 天 / 12 个月 / 5 年 / 自定义日期。
- 地理范围：全球、美国、英国、德国、日本、韩国、中国、中国香港、中国台湾等 19 个常用地区。
- 「分析全部」按设置打开全部组或只打开第一组；「复制全部链接」批量拿走 URL。
- 每组卡片支持单独打开、复制链接、加/去引号、翻译、相关词、收藏、删除。
- 点击单个关键词 chip 直接打开该词的趋势页。

### 词库（历史 + 收藏 + 词根）

- 分析过的关键词自动入库并累计使用次数、记录最近使用时间。
- 收藏与词根是同一记录的标记，不再是三份互不相干的列表。
- 搜索、按标记筛选、按最近使用 / 使用次数 / 名称排序。
- 单条操作：加入输入框、加入第一组对比、复制、切换收藏、切换词根、删除。
- 批量操作：加入输入框、收藏、取消收藏、标记词根、删除。
- 导出 JSON / CSV，导入 JSON（与现有词库合并）。

### Trends 页面注入

在 `trends.google.com` 的关键词行、搜索结果表格、搜索框旁注入：

- 复制
- 对比（与第一组关键词一起打开）
- 分析（发送到侧边栏）
- 引号（在 URL 的 `q` 参数里切换双引号）
- 删除（仅搜索结果表格/搜索框的紧凑模式，把该词从当前对比中移除）
- 词库标记：★ 收藏、根 词根、数字 已分析次数

相关查询区域额外提供「分析这组相关词」按钮。

### 右键菜单

选中网页文字后右键：

- 「分析选中关键词」：把选中文字送入侧边栏，作为新的一组。
- 「与对比组一起打开」：把选中文字追加到第一组关键词后打开 Trends。

### 设置

- 分析全部时的打开方式。
- Trends 界面语言（中文 / English）。
- 页面注入开关：快捷按钮、词库标记。
- 翻译目标语言（11 种）、翻译后自动复制。
- 导出 / 导入全部数据、恢复默认。

## 安装

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录。
4. 点击工具栏图标打开侧边栏；首次使用建议先点「示例」看输入格式。

无需构建、无 npm 依赖，目录即安装包。

## 数据与隐私

- 所有设置、输入、词库都保存在 `chrome.storage.local`，不经过任何自建服务器。
- 翻译请求发往 `translate.googleapis.com` 的公开端点；相关词请求发往 `suggestqueries.google.com`。
- 不加载远程脚本，不注入分析统计，不发埋点。
- 注：这两个 Google 免费端点没有稳定性承诺，请求失败时界面会显示错误，不影响其他功能。

## 本地校验

```bash
node --check background.js
node --check sidepanel.js
node --check content.js
node --check shared.js
node tools/smoke-test.cjs
python3 tools/make-icons.py   # 重新生成图标
```

## 已知限制

- Google Trends 的页面结构会变，注入脚本使用常见类名（`.progress-label`、`.search-term-wrapper`、`.fe-related-queries` 等）并加了防重复标记；如果 Google 改版导致按钮不出现，改 `content.js` 里的选择器即可。
- Google Trends 一组最多对比 5 个关键词，超出部分会被截断并在卡片上提示。
- 翻译和相关词依赖 Google 免费接口，频繁请求可能被限流。
- 自定义时间的格式直接使用 Google Trends 的 `YYYY-MM-DD YYYY-MM-DD` 约定。
